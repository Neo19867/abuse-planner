# Android-приложение

Приложение открывает актуальную версию планировщика с GitHub Pages в защищенном WebView.
Данные сохраняются локально на телефоне средствами WebView. Telegram-вход и перенос данных
между устройствами работают так же, как в браузерной версии.

## Получение APK

Workflow `Build Android APK` собирает устанавливаемый debug APK при изменениях в папке
`android-app`. Готовый файл находится в артефакте `shift-coef-planner-v2.1.2.apk` соответствующего
запуска GitHub Actions.
